# Focus Flow

Персональный local-first таск-трекер на React/TypeScript. Он объединяет
быстрый захват задач, Сегодня, проекты, три вида Входящих, календарь и
дедлайны, матрицу Эйзенхауэра, поиск и фильтры, Помодоро, привычки,
корзину/архив и настраиваемое оформление.

Текущая реализация — браузерный MVP. Она проверяет продуктовые сценарии и
адаптеры, но ещё не является Tauri-сборкой для Ubuntu.

## Запуск с нуля

Понадобятся [Git](https://git-scm.com/downloads), Node.js 18.19 или новее и
`npm` (он устанавливается вместе с Node.js). Проверить версии можно так:

```bash
git --version
node --version
npm --version
```

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/S0K0lAN/Tracker.git
   cd Tracker
   ```

2. Установите зафиксированные в `package-lock.json` зависимости:

   ```bash
   npm ci
   ```

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

4. Откройте на компьютере `http://127.0.0.1:4173`. При первом открытии
   приложение автоматически загрузит демонстрационные данные.

Чтобы остановить сервер, вернитесь в терминал и нажмите `Ctrl+C`. При
следующих запусках достаточно выполнить `cd Tracker` и `npm run dev`.

### Production-сборка локально

```bash
npm run build
npm run preview
```

После запуска откройте `http://127.0.0.1:4173`.

### Открытие с телефона

Dev-сервер слушает локальную сеть. Подключите телефон и компьютер к одному
Wi-Fi и откройте `http://<локальный-IP-компьютера>:4173`. Текущий локальный
IP можно узнать командой `ip -4 -brief address show scope global`.

Не пробрасывайте порт 4173 в интернет: это сервер разработки без production-
защиты и авторизации.

## Демо-данные

При первом запуске приложение создаёт воспроизводимый демонстрационный набор:
проекты, задачи разных приоритетов и состояний, пересекающиеся временные слоты,
многодневные дедлайны, теги, подзадачи, напоминания, вложения и историю
привычек. Даты рассчитываются относительно дня запуска.

Если в браузере уже есть локальные данные, откройте «Настройки → Данные» и
нажмите «Сбросить», чтобы загрузить актуальный demo-набор из
`src/domain/seed.ts`. Существующие локальные изменения при этом будут заменены.

Маршруты: `/today`, `/inbox`, `/projects`, `/calendar`, `/matrix`, `/search`,
`/habits`, `/trash`, `/settings`.

## Что реализовано

- Создание и редактирование задач с проектом, датами, важностью,
  вычисляемой срочностью, тегами, напоминаниями, подзадачами и вложениями.
- Просмотр изображений/PDF/текста, голосовой capture с русским parser и
  текстовым fallback.
- Проекты, глобальный поиск, сохранённые фильтры и сортировка Входящих.
- Входящие в виде списка, доски или календарной сетки.
- Календарь на год, месяц, неделю, три дня и день; полный список задач ячейки месяца и диапазонная диаграмма дедлайнов на неделю/месяц/год.
- Мягкое удаление, восстановление, окончательное удаление и отдельный архив.
- Привязанный к задаче Помодоро и накопление минут фокуса.
- Привычки с описанием, десятью иконками и индивидуальным ритмом.
- Светлая/тёмная тема, акценты, встроенные и пользовательский фон.
- Schema v2, миграция старых snapshot, localStorage backup/recovery.
- Unit/component, Playwright E2E, WCAG AA и performance gate на 500 задач.

## Статус Google Drive

В приложении есть явно подписанный демо-провайдер и контрактно
протестированный REST-адаптер Drive API v3 для `appDataFolder`. Полный live
OAuth smoke требует отдельного Google OAuth client ID и тестового аккаунта;
секреты не входят в проект и OAuth-токены не сохраняются в snapshot.

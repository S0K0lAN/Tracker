# Расширенные функции Focus Flow

## Статус

- Версия браузерного MVP: schema v2.
- Дата актуализации: 31 июля 2026 года.
- Область документа: реализованные пользовательские сценарии, хранение, ограничения и проверки.
- Подробная трассировка критериев: [feature-acceptance.md](feature-acceptance.md).

Focus Flow остаётся персональным local-first приложением. Все описанные ниже
изменения сначала применяются локально и не ждут сеть. Браузерная версия
проверяет продуктовые сценарии, но не заменяет будущую Tauri-сборку и live
OAuth-проверку Google Drive.

## Навигация и рабочие страницы

| Маршрут | Назначение |
|---|---|
| `/today` | Просроченные задачи, запланированные на сегодня и дедлайны сегодня |
| `/inbox` | Все активные задачи, включая задачи проектов; список, доска и календарь |
| `/projects` | Создание проектов, обзор и задачи выбранного проекта |
| `/calendar` | Неделя, месяц и отдельная диаграмма дедлайнов |
| `/matrix` | Четыре квадранта важности и вычисленной срочности |
| `/search` | Поиск по задачам, проектам, тегам и сохранённым фильтрам |
| `/habits` | Привычки, индивидуальный ритм, прогресс и серии |
| `/trash` | Корзина и архив завершённых задач |
| `/settings` | Оформление, поведение, синхронизация, плагины и локальные данные |

Неизвестный URL показывает контролируемую страницу 404. Прямые ссылки,
Back/Forward и reload поддерживаются History API router.

## Задачи и редактор

Название остаётся единственным обязательным полем. Полный редактор поддерживает:

- дополнительный текст, проект, подзадачи и теги;
- плановое начало и единый дедлайн;
- низкую или высокую важность;
- автоматическую срочность по дедлайну, индивидуальный порог и ручное
  переопределение;
- до пяти напоминаний;
- до пяти файлов или изображений размером до 1 МБ каждый;
- вставку изображения из буфера и drag-and-drop файлов;
- запуск привязанного к задаче Помодоро.

Проект, важность, порог срочности и ручная срочность выбираются через общий
combobox. Он показывает выбранное состояние, пояснения и цвет проекта.
Проектный список поддерживает поиск. Доступны мышь/touch, `Enter`, `Space`,
стрелки, `Home`, `End` и `Escape`; `Escape` закрывает только открытый список и
возвращает фокус на trigger, не уничтожая черновик редактора.

На карточке важность обозначена и иконкой, и текстом «Обычно»/«Важно», поэтому
смысл не зависит только от цвета. Также видны срочность, проект, дедлайн,
подзадачи, вложения, теги и накопленные минуты фокуса.

### Вложения

Из редактора можно открыть изображение, PDF или текстовый файл в отдельном
viewer, скачать его и масштабировать изображение. Viewer закрывается кнопкой
или `Escape`, после чего фокус возвращается к источнику.

В браузерном MVP бинарные данные хранятся как data URL внутри локального
snapshot. Лимиты защищают `localStorage` от неконтролируемого роста. Для
desktop/Android реализации они должны быть перенесены в отдельный Blob/File
store, а в JSON должны остаться метаданные и content hash.

### Голосовой ввод

Кнопка «Надиктовать задачу» использует доступный в браузере Web Speech API с
локалью `ru-RU`. Запись не сохраняется приложением. При неподдерживаемом API
остаётся текстовый fallback, поэтому ручное создание не блокируется.

Детерминированный parser выделяет:

- название;
- `сегодня`, `завтра`, `послезавтра` или следующий названный день недели;
- время после «в», «к» или «до»;
- высокую важность;
- `#теги`;
- подсказку проекта.

Результат сначала появляется в preview. Пользователь явно применяет или
отменяет распознанные поля и после применения может исправить любое поле
обычным редактором. Распознавание речи браузером может использовать сервис
поставщика браузера; Focus Flow сам не отправляет и не хранит аудиозапись.

## Представления задач

### Сегодня

Страница использует локальную календарную дату. Она разделяет просроченные
активные задачи, задачи с `startAt` сегодня и задачи с дедлайном сегодня.
Задача, у которой и начало, и дедлайн сегодня, не дублируется.

### Проекты

Проект создаётся с названием, описанием и цветом. Пустое имя не принимается.
Карточка проекта показывает количество активных и завершённых задач. После
открытия проекта отображается его собственный список; новый проект сразу
появляется в searchable selector редактора задачи. Создание задач и проектов
сохраняется после reload.

### Входящие

«Входящие» по-прежнему охватывают все задачи, включая проектные, но исключают
корзину и архив. Доступны:

- сортировка по дате создания, ближайшему дедлайну, важности или названию;
- фильтр проекта, тегов и быстрые фильтры;
- режимы «Список», «Доска» и «Календарь»;
- показ завершённых и массовая архивация завершённых.

Доска группирует тот же отфильтрованный набор по проектам. Календарная сетка
использует плановое начало, а при его отсутствии — дедлайн; задачи без обеих
дат остаются в отдельном лотке. Выбранные вид и сортировка сохраняются в
настройках.

### Поиск и сохранённые фильтры

Глобальный поиск одновременно находит:

- задачи по названию, тексту и тегам;
- проекты по названию и описанию;
- теги;
- сохранённые фильтры.

Визуальный конструктор фильтра поддерживает проект, несколько тегов с
семантикой «любой/все», важность, вычисленную срочность и статус. Фильтр можно
именовать, сохранить, повторно применить и удалить. Поиск и фильтрация не
изменяют исходные задачи.

### Календарь и дедлайны

Задача с `startAt` остаётся календарным событием. Задача только с дедлайном
теперь дополнительно видна как deadline marker в недельном и месячном режимах.
Отдельная диаграмма дедлайнов показывает все задачи с дедлайном в порядке
срока. Поэтому дедлайн не превращается в плановое начало и не меняет
семантику time blocking.

### Жизненный цикл, корзина и архив

Статусы задачи: `active`, `completed`, `archived`, `deleted`.

- Завершение обратимо и не удаляет данные.
- «В корзину» выполняет мягкое удаление и запоминает предыдущий статус.
- Из корзины задачу можно восстановить или удалить окончательно после
  подтверждения.
- Завершённую задачу можно архивировать отдельно либо массово.
- Архив отделён от корзины и поддерживает восстановление.

## Помодоро

Меню активной задачи запускает глобальный dock-таймер с циклами:

- фокус — 25 минут;
- короткий перерыв — 5 минут;
- длинный перерыв — 15 минут после четырёх фокус-сессий.

Доступны старт, пауза и сброс. Текущая задача, режим, остаток времени,
`runningSince` и число завершённых сессий сохраняются. После полного
фокус-цикла к задаче добавляются минуты фокуса. Браузерный MVP не обещает
системный таймер при полностью закрытом браузере.

## Привычки

Привычка содержит название, необязательное описание, цвет, расписание по дням
недели, собственные completions и одну из десяти доступно подписанных иконок.

«Ваш ритм» вычисляется для каждой привычки отдельно на скользящем окне семи
локальных дней:

- в знаменатель входят только запланированные для этой привычки дни;
- прогресс и серия используют только её собственные completions;
- незапланированные дни визуально отличаются и не разрывают серию;
- переключение одной привычки не меняет другую.

## Оформление и фоны

Кроме светлой/тёмной/системной темы, акцента и плотности доступны:

- «Без фона»;
- встроенные пресеты «Туман», «Рассвет» и «Лес»;
- собственное локальное изображение до 1,5 МБ;
- регулируемое затемнение фона для сохранения читаемости.

Выбор применяется ко всему пространству и сохраняется. Собственный фон в
браузерном MVP хранится как data URL в snapshot; будущий platform adapter
должен вынести его в отдельное файловое хранилище.

## Данные и миграция

Текущая версия snapshot — `2`. При загрузке `normalizeAppState`:

- добавляет новые обязательные поля старым задачам, проектам и привычкам;
- нормализует статусы и стандартный порог 72 часа;
- добавляет `savedFilters`, `pomodoro` и новые настройки;
- сохраняет неизвестные поля верхнего уровня и сущностей через структурное
  расширение, чтобы не уничтожить будущие plugin-данные.

`LocalStorageAdapter` валидирует JSON через нормализатор. Перед каждой записью
предыдущий основной snapshot копируется в `focus-flow.state.v1.backup`.
Повреждённый основной snapshot восстанавливается из backup, если он валиден.
Это recovery-механизм браузерного прототипа, а не эквивалент атомарного
файлового адаптера Tauri.

OAuth-токен не попадает в snapshot, localStorage или Drive-файл. Введённый в
настройках token существует только в локальном состоянии формы.

## UI/UX, доступность и производительность

Интерфейс использует общие цветовые токены, размеры и Lucide-иконки.
Интерактивные SVG центрируются внутри button/nav primitives. Для dropdown и
меню устранены clipping и перекрытие плавающей кнопкой. Touch targets
checkbox задачи, выбора цвета проекта, иконок и дней привычки имеют 44×44 px
без визуального утяжеления внутренних маркеров.

Редактор задачи, viewer вложения и мобильный drawer удерживают клавиатурный
фокус внутри активного modal scope, поддерживают `Escape` и возвращают фокус
на исходный control. Фоновый интерфейс на время открытия получает `inert`.

Анимации используют отдельную easing-переменную: значение transition больше
не интерпретируется браузером как скрытая animation delay. Page/editor
анимации короткие и не оставляют постоянный transform stacking context.
`prefers-reduced-motion` и пользовательская настройка отключают движение.
Смена маршрута сбрасывает scroll мгновенно, поэтому fixed mobile header не
мерцает во время compositor smooth-scroll.

Для длинного списка карточки используют `content-visibility` и containment,
который временно снимается у открытого action menu. Performance gate
создаёт 500 задач и проверяет первую отрисовку, p95 кадра и долю длинных
кадров.

## Автоматические проверки

Обязательная передача выполняется командами:

```bash
npm test
npm run build
npm run test:e2e
```

Основное evidence:

- `src/domain/models.test.ts` — срочность и просрочка;
- `src/domain/voiceParser.test.ts` — русский parser и границы слов;
- `src/pages/HabitsPage.test.tsx` — ритм, независимые completions, иконки и
  описание;
- `src/NewFeatures.test.tsx` — страницы, проекты, lifecycle, layouts,
  сортировка, keyboard Escape и deadline markers;
- `src/core/sync/GoogleDriveAdapter.test.ts` — контракт Drive API;
- `e2e/app.spec.ts` — базовый task loop и старые рабочие представления;
- `e2e/new-features.spec.ts` — новые маршруты, persistence, поиск, фильтры,
  вложения, голосовой fallback, Pomodoro, фоны и привычки;
- `e2e/ui-quality.spec.ts` — WCAG AA/overflow и прокрутка 500 задач.

Независимый visual QA дополнительно проверяет обе темы на 1440×900 и 390×844,
keyboard/focus, геометрию dropdown, contrast и stacking.

## Продуктовые ориентиры

Из Todoist использованы принципы быстрого захвата, отдельного Today,
progressive disclosure, сохранённых фильтров, нескольких видов и ясной
важности. Из SingularityApp — сочетание проектов, календаря, привычек,
Помодоро, архива, голосового capture и оформления. Корпоративная сложность,
совместная работа и marketplace не переносились в персональный MVP.

## Честные границы браузерного MVP

- Нет Tauri shell, приватного JSON-файла, системного secret store и
  платформенных уведомлений.
- Google Drive adapter контрактно проверен, но live OAuth smoke не выполнен.
- Вложения и custom background временно занимают localStorage.
- Нет повторяющихся задач, импорта/экспорта, project rename/delete,
  drag-and-drop между board-колонками и фоновой работы Помодоро при закрытом
  приложении.
- Web Speech зависит от браузера и его политики обработки речи.
